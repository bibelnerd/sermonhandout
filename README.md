# sermonhandout
Ein einfaches Programm, das Predigthandouts schnell in andere Sprachen übersetzt.
Gib eine Bibelstelle, den Predigttitel und eine Predigtzusammenfassung an und das Programm gibt den Bibeltext in einer Übersetzung in der Zielsprache, zusammen mit einer DeepL-Übersetzung der Zusammenfassung aus. 
Für die Übersetzung ist ein (kostenloser) DeepL-API-Key nötig. Dieser kann unter https://www.deepl.com/de/pro#developer bezogen werden.

# Sprachen
Es werden folgende Sprachen mit folgenden Bibelübersetzungen unterstützt:
* Chinesisch: Chinese Union (Traditional) 和合本
* Englisch: English Standard Version 2001, 2016
* Französisch: Nouvelle Bible Segond, 2002
* Indonesisch: Terjemahan Baru
* Italienisch: Nuova Riveduta, 2006
* Japanisch: 新改訳聖書 第三版, New Japanese Bible - Shinkai-yaku, 2003
* Koreanisch: 새번역
* Polnisch: Biblia warszawska, 1975
* Portugiesisch (PT): Nova Versão Internacional
* Portugiesisch (BRA): Tradução Brasileira, 2010
* Russisch: русский Синодальный Перевод
* Spanisch: Nueva Versión Internacional
* Ukrainisch: Бiблiя. Переклад Патріарха ФІЛАРЕТА (Денисенка), 2004

# Bekannte Probleme
* Wird eine ungültige Bibelstelle eingegeben, hängt sich das Programm auf und muss neu gestartet werden.
